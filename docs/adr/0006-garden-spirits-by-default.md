# Garden Spirits are every build's default look, ahead of adoption

On 2 November 2026 Afolabi made painted Garden Spirits the default in every build, production included, without waiting for the opt-in adoption flow of ADR 0005. The look is chosen per page: Garden Spirits draw the frozen version 2 parameters of each address and variant, `?critters=1` draws version 1 with its 3D, and the development server keeps the October inked drawing at `?critters=2`; the old `?critters=garden` review links still work and `VITE_GARDEN_REVIEW` is gone. Stored identities, feast appearances, the server and the generators are unchanged, so every member, locked critters and past results included, is redrawn as a Garden Spirit without being asked, and `?critters=1` restores what they had. Garden Spirits have no mesh, so the default stage is portraits only. This supersedes ADR 0005's opt-in requirement for how critters look, not for what is stored: rendering stored versions, choosing a production version for the art and a preview-and-Keep adoption flow remain open. Rejected: a review build that shows the art only at `?critters=garden` (the default would stay version 1).
