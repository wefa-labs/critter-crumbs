How this page is built

  • Each phone is a frame that loads the app’s own packages/app/src/styles/app.css with that pane’s tokens on :root, so the app’s rules and breakpoints lay it out at 375 px.
  • The screens repeat the markup of the app’s components and use its copy, with the rehearsal seed’s eight accounts and statements. They are mock-ups, not the running app.
  • Version 1 critters come from a port of the frozen generator and the app’s portrait renderer. Version 2 runs the #31 draw through the same renderer with the element parts added.
  • 3D stills use three.js 0.185.1 from jsDelivr with the app’s camera, lights and mesh builder. Version 2 meshes are a prototype of Design System §5.3.
  • The arrival stand-ins are the deck’s interior scenes. Deck art is the deck’s four paintings, matched to each account’s version 2 element.
